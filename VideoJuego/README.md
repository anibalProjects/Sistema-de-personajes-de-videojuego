# 🎮 Sistema de Personajes de Videojuego

¡Bienvenido al **Sistema de Personajes de Videojuego**! 



---

## 🚀 Características

- **👥 Personajes disponibles**:
  - 🏹 **Arquero**: Maestro de los ataques a distancia con habilidades como disparar flechas y volar.
  - 🗡️ **Asesino**: Experto en sigilo con golpes críticos y habilidades evasivas.
  - 🛡️ **Guerrero**: Un tanque con ataques cargados y habilidades defensivas.
  - 🔮 **Mago**: Usuario de magia con hechizos poderosos y habilidades de curación.
  - 🧙‍♂️ **Hechicero**: Invocador de golems con habilidades mágicas y defensivas.

- **⚔️ Sistema de batalla**:
  - Los jugadores eligen dos personajes para enfrentarse en un combate por turnos.
  - Cada personaje tiene habilidades únicas que pueden usar durante su turno.
  - El ganador es el último personaje en pie. ¡El nombre del ganador aparecerá al final! 🏆

- **📋 Menú interactivo**:
  - Ver personajes y sus estadísticas.
  - Explorar las habilidades de cada personaje.
  - Iniciar una batalla épica.
  - Salir del programa.

---
## 🖥️ Requisitos

- **Java**: Versión 8 o superior.
- **IDE recomendado**: Visual Studio Code con la extensión de Java instalada.

---

## 📖 Cómo usar el programa

1. **Ejecuta el programa**:
   - Compila y ejecuta el archivo `App.java`.
   - Se mostrará un menú principal con las siguientes opciones:
     - `1`: Ver personajes y sus estadísticas.
     - `2`: Ver habilidades de un personaje.
     - `3`: Empezar batalla.
     - `4`: Salir.

2. **Explora los personajes**:
   - Usa la opción `1` para ver la lista de personajes disponibles.
   - Usa la opción `2` para seleccionar un personaje y ver sus habilidades.

3. **Inicia una batalla**:
   - Selecciona la opción `3` para elegir dos personajes y enfrentarlos en un combate por turnos.
   - El programa mostrará las acciones de cada personaje y determinará al ganador. 🏅

4. **Salir del programa**:
   - Selecciona la opción `4` para cerrar el programa.

## 🧙‍♂️ Ejemplo de habilidades de personajes

### 🏹 Arquero
- **Flechas**: 15 de daño.
- **Volar**: Incrementa el daño durante 3 rondas.
- **Reestablecer Flechas**: Recarga las flechas disponibles.

### 🛡️ Guerrero
- **Ataque**: 20 de daño.
- **Cargar Ataque**: Incrementa el daño del próximo ataque en 10.
- **Defender**: Activa un escudo que bloquea el próximo ataque.

### 🔮 Mago
- **Ataque**: 5 de daño.
- **Lanzar Hechizo**: 20 de daño.
- **Escarcha Helida**: 35 de daño.

### 🧙‍♂️ Hechicero
- **Ataque**: 5 de daño.
- **Lanzar Hechizo**: 20 de daño.
- **Invocar Golem**: Invoca un golem para atacar o defender.
